小笔记本 · 更新静态站
====================

这是什么
--------
给你维护「当前最新版本」的静态网站目录。
别人的小笔记本只会请求：
  - version.json   （版本号、说明、下载相对路径）
  - releases/下的文件 （真正的升级 exe）

本地预览
--------
1. 进入本文件夹
2. 用浏览器打开 index.html
   若 version.json 读失败，可在本目录执行：
   python -m http.server 8765
   然后访问 http://127.0.0.1:8765/

发布给别人用（必须）
--------------------
静态站必须放到「公网能打开」的地方，例如：
  - 阿里云 OSS 开启静态网站
  - Cloudflare / GitHub Pages
  - 任意能托管静态文件的空间

上传整个文件夹后，记下根地址，例如：
  https://your-bucket.oss-cn-hangzhou.aliyuncs.com/mn-update/
小笔记本里把更新地址设成这个根 URL（功能随后可接上）。

发新版本步骤
------------
1. 编译出新的 小笔记本.exe
2. 复制到 releases/，建议改名 MiniNotebook_x.y.z.exe
3. 编辑 version.json：version / file / notes / publishedAt
4. 编辑 version.txt：第一行同一版本号
5. 重新上传整个站（或至少 version.* 与新 exe）

和本地 _更新 的关系
------------------
本地 _更新 文件夹 = 离线丢包。
本静态站 = 在线检查更新。
两者可以并存。

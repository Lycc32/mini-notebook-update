# 1.0.40

## 变更摘要

- **精致开机动画（欢迎相位）**：暗幕柔入 → 单层椭圆呼吸柔光（alpha≤22）→ 标题 EaseOutCubic 上浮淡入（约 0.92→1.0）+ 发丝下划线自左向右展开 → 「欢迎使用」错峰淡入 → **细圆环进度**（半径≈24）替代粗进度条；末 0.25s 整体淡出进屋。无轨道球/同心波纹/大晕。欢迎总时长约 4.0s。
- **更新进度相位**：与欢迎同语汇——克制柔光圆标 + 圆环扫过 + 细进度条，避免两套视觉。
- **网址快捷备注**：`QuickItemInfo.Note`；持久化 `U|url\u001F备注`（旧 `U|url` 兼容）；有备注时卡片主标题显示备注、副行显示网址；添加网址两步（URL→可选备注）；右键「改备注」。筛选匹配备注。
- **实时拖宽**：每动 ≤16ms 超轻量布局（list/chips/composer 顶行即时跟宽）；约 60ms 中等回流含录入字段；松开再完整布局+圆角+存盘。内容随鼠标扩张/收缩，不再“松手才动”。

## 兼容说明

- 快捷项旧格式可读；有备注时写入含 U+001F 分隔。
- 外层 `小笔记本.exe` 不被本版构建覆盖；产物仅写入 `_build\MiniNotebook_1.0.40.exe`。
